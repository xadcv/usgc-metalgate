# USGC Metalgate

A cyan [Omarchy](https://omarchy.org) theme inspired by [USGC-METALGATE](https://github.com/usgraphics/usgc-themes) (PN# 5200-050) from the United States Graphics Company. Metal gate transistor aesthetic: black background, fluorescent cyan foreground, fluorescent blue cursor, olive selection with fluorescent yellow text.

Part of the [USGC themes collection](https://github.com/usgraphics/usgc-themes) ported to Omarchy.

## Preview

![backgrounds/1-spruce.png](backgrounds/1-spruce.png)

A retro Windows 98 "Spruce" solid-color desktop pairs with the scheme.

## Install

```bash
omarchy theme install https://github.com/xadcv/usgc-metalgate
```

Then switch via `omarchy theme set "Usgc Metalgate"` or `Super + Ctrl + Shift + Space`.

## What's themed

- Hyprland (borders)
- Waybar
- Alacritty / foot / kitty / ghostty (via `colors.toml`)
- btop
- Neovim (tokyonight-night via LazyVim)
- VS Code (Default Dark Modern)
- Chromium
- GTK / icons (Adwaita-dark, Yaru-blue)

## Palette

| Role | Hex |
|------|-----|
| Foreground | `#00ffff` |
| Background | `#000000` |
| Accent (cyan) | `#00ffff` |
| Selection bg | `#666600` |
| Selection fg | `#ffff00` |
| Cursor | `#0000ff` |

ANSI bright colors are fluorescent CMYK: `#ff0000`, `#00ff00`, `#ffff00`, `#0000ff`, `#ff00ff`, `#00ffff`.
